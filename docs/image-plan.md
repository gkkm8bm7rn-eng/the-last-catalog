# План изображений для каталога

## Главное правило

Финальная галерея не использует разрезанные коллажи. Каждый кадр генерируется и дорабатывается как самостоятельное изображение с собственной композицией, светом, перспективой и достаточным пространством по краям. Все изображения одной карточки должны выглядеть как одна съёмочная серия.

Базовый формат: квадрат 1:1. Для hero-версий допускается дополнительный вертикальный 4:5 вариант для Dprofile и промо.

Общий визуальный язык: тёплый светло-серый / молочный / песочный фон, камень, мягкий боковой свет, много воздуха, музейная предметная съёмка, минимум цвета. Материал выбирается по смыслу конкретного объекта; стекло не должно становиться повторяющимся мотивом всей коллекции. Цветовые исключения должны быть смысловыми, а не декоративными.

## 001 — Тишина — ЗАФИКСИРОВАНО

Статус: финальная серия утверждена.

Мастер-образ: тонкая почти бесцветная прозрачная плёнка, а не стекло. Внутри должна читаться пустота; оболочка нужна только для того, чтобы сделать эту пустоту видимой. Свет песочно-молочный, нейтрально-тёплый, без золотого или персикового свечения. Маркировка на камне немного заметнее первоначальной версии, но остаётся деликатной.

Финальные ассеты:
1. `001/01-hero.webp` — главный канонический кадр объекта на каменном постаменте.
2. `001/02-material.webp` — макро плёнки и точки натяжения; надпись «НЕ ОТКРЫВАТЬ / ТИШИНА МОЖЕТ ИСЧЕЗНУТЬ».
3. `001/03-catalog.webp` — чистый альтернативный каталожный ракурс без человека.
4. `001/04-scale.webp` — рука приближается к объекту, не касаясь его.

Надписи на постаменте: «ОБЪЕКТ 001», «ТИШИНА», «ИР 92». Дополнительная фраза при необходимости: «ТИШИНА МОЖЕТ ИСЧЕЗНУТЬ. БЕРЕГИТЕ.»

## 002 — Приватность

1. Главный образ: закрытый матовый объект без интерфейса и отверстий.
2. Деталь: макро непрозрачного материала.
3. Закрытая сторона: форма, которая визуально ничего не сообщает наружу.
4. Каталожная съёмка: объект на фирменном постаменте.

## 003 — Тёмное небо

1. Главный образ: детский калейдоскоп с узнаваемой геометрией; тубус — тёмное городское небо.
2. Взгляд в окуляр: реалистичное тёмное звёздное небо, сформированное калейдоскопической симметрией.
3. Обойма: отдельно показать разноцветные кристаллы, зеркала и механизм, из которых искусственно складывается видимость настоящего неба.
4. Каталожная съёмка: калейдоскоп на фирменном постаменте.

## 005 — Случайная встреча

1. Главный образ: две независимые траектории пересекаются в одной точке.
2. Деталь: единственный световой/оптический всплеск в точке встречи.
3. До пересечения: показать самостоятельность двух форм.
4. После пересечения: каждая траектория продолжает свой путь.

## 006 — Медленное течение времени

1. Главный образ: геометрически точная стеклянная лента Мёбиуса.
2. Деталь: натуральный песок внутри хрупкого прозрачного канала.
3. Время: золотая 24-часовая шкала, выгравированная по непрерывной поверхности; разметка должна быть последовательной и математически правдоподобной.
4. Каталожная съёмка: объект на фирменном постаменте.

## 004 — Место автора

Финальный секретный объект не требует обычной четырёхкадровой галереи. Основной кадр: пустой фирменный постамент, режиссёрское кресло «МЕСТО АВТОРА 004» и зеркало с физически достоверным отражением. Изображение выдаётся только в финале.
