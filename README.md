# ПОСЛЕДНИЙ КАТАЛОГ

**Каталог того, что ещё можно потерять.**

Интерактивный digital-проект о редких человеческих состояниях, созданный в соавторстве с ИИ.

## Текущая коллекция

- 001 — Тишина
- 002 — Приватность
- 003 — Тёмное небо
- 005 — Случайная встреча
- 006 — Медленное течение времени
- 004 — скрытый финальный объект / Место автора

## Принцип галереи

Каждый товар получает отдельную галерею из самостоятельных изображений. Коллажи не используются как финальные изображения и не режутся на фрагменты. Для каждого объекта предусмотрены отдельные кадры: hero, деталь, смысловой/механический кадр и каталожная съёмка.

Сейчас интерфейс использует намеренные нейтральные плейсхолдеры. Финальные изображения будут добавлены после отдельного визуального прогона по каждому объекту.

## Стек

React + Vite. Навигация сделана через hash-маршруты, чтобы проект корректно работал как статический сайт на GitHub Pages.

## Запуск

```bash
npm install
npm run dev
```
