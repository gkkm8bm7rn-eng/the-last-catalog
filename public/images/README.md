# Финальные изображения каталога

В этой папке хранятся только самостоятельные финальные изображения. Нарезки коллажей и изображения с фрагментами соседних кадров не используются.

## Общий принцип

- один файл = один законченный кадр;
- единый мягкий боковой свет и спокойная музейно-каталожная среда;
- основной формат: квадрат 1:1, не менее 1600×1600 px;
- предпочтительный web-формат: WebP высокого качества;
- встроенный текст на изображении — только когда он является частью самого объекта;
- интерфейсные подписи, названия и характеристики добавляются HTML/CSS на сайте, а не запекаются в изображение.
